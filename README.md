# AIT SAID Mehdi — student portfolio

**Student name:** AIT SAID Mehdi

## Project description

Responsive personal portfolio for a student / junior developer (WAMD, ENSTA, TD/TP 1).
A visitor can see who the student is, their skills, projects, education and contact details.
The layout works on a phone, a tablet and a desktop.

## Technologies used

- HTML5 (semantic structure)
- CSS3 (responsive layout)
- JavaScript (DOM and events)

## Implemented features

- Sections: Home, About, Skills, Projects, Education, Contact
- Separate files: index.html, css/style.css, js/script.js
- Mobile menu (button click, class toggle)
- Skill filters (All, Languages, Web, Tools)
- Contact form checks for name, email and message, then shows a confirmation
- Scroll spy on the navigation
- Sticky header and a back-to-top button

## How to open

Open `index.html` in Chrome or Firefox. Use DevTools device mode to check phone and tablet widths.

Optional: publish the same folder with GitHub Pages.
